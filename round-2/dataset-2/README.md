## Full Summary

This dataset artifact tried to assemble measured water boiling-point records paired with site elevation and station pressure from 0 to 4,000 m, with a target of at least 25 Tier A sites and a fixed held-out set of at least 8 sites. The search covered eight broad web queries, follow-up fetches of the most promising pages, and a Hugging Face search. No Tier A or Tier B record could be verified. The best lead is Forbes (1857), which reports 17 boiling-point and barometer pairs at Alpine stations, but its table is OCR-garbled in the archive text and the site elevations are not in the R copies, so no row passed the drop rules. The Denver Public Library index card was dropped because it has no date and no thermometer uncertainty. The Snyder calibration tables and the NBS steam tables are equation-derived and are kept only as Tier C reference. The delivered dataset therefore has zero measured rows. Its one group holds four Tier C reference values (212.0, 210.2, 208.4 and 206.6 F at 0, 1,000, 2,000 and 3,000 ft, converted to C), labelled as not measured. The full, mini and preview JSON files pass the exp_sel_data_out schema, checked with jsonschema directly because the skill's command-line validator rejects workspace paths. The held-out rule is not defined, since no Tier A sites exist and no residuals are computed. Next steps: transcribe the Forbes table from the page image, obtain cited elevations for each site, and match ISD station pressure to each site and time window.
