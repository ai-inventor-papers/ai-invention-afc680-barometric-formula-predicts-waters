## Layman Summary

This artifact provides a small, checked table of the boiling temperature of water at heights from sea level to 4,000 metres, with a comparison against a simple air-pressure formula, so the formula's accuracy can be judged.

## Full Summary

This dataset is a small, schema-checked reference table of the boiling temperature of water from 0 to 4000 m, in 100 m steps (41 rows). Every row is equation-derived: the boiling temperatures come from a barometric-levelling table (deleze.name), not from field measurements. The plan asked for at least 25 independent measured boiling records at named sites, each with elevation, station pressure, and thermometer uncertainty, plus a holdout set of at least 8 sites. Web search did not yield any measured site that could be verified against its source, so the measured-site count is zero and the holdout set is empty. No measured rows were padded in from equation-derived values. The holdout rule (all measured sites in the Americas above 1000 m) is written into the metadata for future use. The table is paired with a formula check: the U.S. Standard Atmosphere 1976 pressure relation combined with an empirical pressure-to-boiling-point fit from a UC Davis calibration note. Residuals against the reference grid have mean -0.004 C and maximum absolute 0.21 C. This agreement shows that the two calculations are consistent with each other; it does not test the formula against measurements, which the hypothesis requires and which this release does not provide. Files: full_data_out.json (41 examples in one dataset group, input = elevation, output = table boiling temperature), mini and preview files, a CSV copy, a JSON Schema, a drop log of rejected sources with reasons, and a README and reproducibility guide.
